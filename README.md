# ☕ Starbucks Sales Dashboard – Power BI Project

## 📌 Project Overview
This project presents an interactive Starbucks Dashboard developed using Microsoft Power BI. The dashboard helps analyze Starbucks sales performance and provides meaningful business insights through data visualization.

## 🎯 Project Objectives
- Analyze overall sales performance.
- Understand customer purchasing trends.
- Identify popular products.
- Analyze sales across different categories.
- Present business insights through interactive dashboards.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- Microsoft Excel
- Data Cleaning
- Data Visualization

## 📊 Dashboard Features
- Interactive KPI Cards
- Sales Performance Analysis
- Product Analysis
- Category-wise Analysis
- Trend Analysis
- Interactive Filters and Slicers

## 📈 Key Skills Demonstrated
- Data Cleaning and Transformation
- Data Modeling
- DAX Calculations
- KPI Development
- Dashboard Design
- Business Data Analysis

## 📁 Project Files
- Power BI Dashboard (.pbix)
- Dataset (.xlsx)
- Dashboard Screenshot (.png)

## 💡 Project Outcome
Created an interactive dashboard to explore sales data and present business information in an easy-to-understand visual format.
